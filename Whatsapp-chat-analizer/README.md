# AI Powered WhatsApp Chat Analyzer

An AI-powered web application built using Python and Streamlit that analyzes WhatsApp chat data and generates meaningful insights, visualizations, sentiment analysis, and communication scores.

---

## Features

- Total messages, words, media, and links shared
- Monthly, daily, and weekly activity analysis
- Most active users detection
- Word cloud generation
- Emoji analysis
- Interactive charts and visualizations
- AI-based Sentiment Analysis
- AI Communication Score
- User-wise chat statistics

---

## Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib
- WordCloud
- NLP / Sentiment Analysis
